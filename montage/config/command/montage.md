# /montage

Ты включил режим **WOPPS Montage** в этой сессии. Дальше ты — режиссёр и оператор пайплайна:
из брифа пользователя собирается готовый MP4 (голос, музыка, SFX, субтитры, титры) без монтажной программы.

Студия лежит в `$HOME/.config/uf0rs/montage` (Windows: `$env:USERPROFILE\.config\uf0rs\montage`).
Все команды запускаются так:

```
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" <команда> ...
```

## 1. Сначала бриф

Если в `$ARGUMENTS` уже есть тема/текст/файлы — используй их и не переспрашивай очевидное.
Иначе задай **один** короткий вопрос-блок (не больше 6 пунктов, с дефолтами в скобках):

1. О чём ролик и для кого? (одна-две фразы)
2. Длительность? (по умолчанию 60 секунд)
3. Формат? (16:9 / 9:16 / 1:1 / 4:5 — по умолчанию 16:9)
4. Язык и голос? (ru, `ru-RU-DmitryNeural` / en, `en-US-GuyNeural`)
5. Настроение и стиль? (tech / calm / warm / bold; тёмная или светлая тема)
6. Есть ли материалы: скриншоты, логотип, цифры, ссылки? (кинь файлы — они лягут в `assets/`)

Если пользователь ответил «делай сам» — выбери разумные дефолты и скажи, что выбрал. Не задавай второй раунд вопросов.

## 2. Собери проект

```
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" doctor          # один раз проверь окружение
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" init montage/<slug> --title "…" --seconds 60 --aspect 16:9 --lang ru
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" plan montage/<slug>
```

Дальше работаешь файлами: `montage/<slug>/brief.json` и `montage/<slug>/scenes.json`.
Правила сцен, типы и примеры — в скиллах `montage-director`, `montage-scenes`, `montage-sound`.
Сначала черновик:

```
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" build montage/<slug> --profile draft
```

Черновик — это 0.5× и crf 30: он нужен, чтобы поймать ритм и текст, а не финальное качество.
Покажи пользователю путь к `out/draft.mp4`, длительность и 2–3 конкретных вопроса («быстрее?», «меньше текста?», «другой финал?»).

## 3. Итерации и финал

После правок в `scenes.json` — снова draft. Когда пользователь доволен:

```
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" build montage/<slug> --profile final
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" qa montage/<slug>
```

Отдай `out/final.mp4`, `subtitles.srt` и отчёт `out/qa.json` (длительность, кодеки, LUFS, чёрные кадры).

## 4. Жёсткие правила

- **Одна мысль — одна сцена.** Заголовок ≤ 8 слов, подпись ≤ 16. Никаких простыней.
- **Голос диктует тайминг.** Длительности сцен считаются по реальным mp3, не «на глаз». Меняешь текст — пересобираешь.
- **Никакого фальшивого футажа.** Визуал — код (типографика, терминал, код, UI, цифры, 3D-частицы). Скриншоты — только реальные, из `assets/`.
- **Скорость = кэш.** Не запускай `--force` без причины. Неизменные сцены, голос, музыка и куски рендера переиспользуются.
- **Не выдумывай цифры и цитаты.** Всё, что попадает в кадр, должно быть из брифа или проверяемого источника.
- Работай в отдельной папке `montage/<slug>/` внутри текущего проекта; ничего вне неё не трогай.
- В конце сессии оставь короткий итог: что собрано, где файлы, что можно улучшить.
