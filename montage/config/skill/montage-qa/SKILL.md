# Приёмка

## Автоматически

```
node "$HOME/.config/uf0rs/montage/bin/montage.mjs" qa montage/<slug>
```

Пишет `out/qa.json` и печатает: длительность, размер, кодек/разрешение/fps, аудио, LUFS, true peak,
чёрные кадры. Норма:

| Параметр | Норма |
|---|---|
| Длительность | совпадает с обещанной ±0.3 с |
| Видео | h264, 1920×1080 (или выбранный формат), 30 fps |
| Аудио | aac, 48 кГц, стерео |
| Громкость | −16…−12 LUFS, true peak ≤ −1.5 dBTP |
| Чёрные кадры ≥ 0.6 с | допустимы только как осознанная пауза |
| Субтитры | `subtitles.srt` непустой, тайминги внутри ролика |

## Глазами (обязательно перед финалом)

- [ ] Первые 3 секунды цепляют без звука.
- [ ] Ни один заголовок не обрезан и не наезжает на подпись.
- [ ] В 9:16 текст не липнет к краям (безопасная зона ~7.5 %).
- [ ] Цифры в `stats` читаются за 1.5 с.
- [ ] В `terminal`/`code` успеваешь прочитать до смены сцены.
- [ ] Субтитры не перекрывают ключевой визуал.
- [ ] Финал: логотип, одна строка, CTA — и не длиннее 6 с.
- [ ] Нет сцены, где ничего не происходит.

## Ушами

- [ ] Речь без запинок и «эээ» (edge-tts иногда ломает длинные числа — переформулируй).
- [ ] Музыка не перекрывает голос ни в одной фразе.
- [ ] Нет щелчков на стыках реплик.
- [ ] Финал не обрывается: есть фейд.

## Типовые дефекты и лечение

| Дефект | Лечение |
|---|---|
| Реплика не влезает в сцену | короче текст или `duration` больше (при отсутствии vo) |
| Сцена «висит» | добавь `vo` или сократи `duration` |
| Слишком громко | `energy` ниже у плотных сцен; `--no-music` как крайняя мера |
| Скучный ритм | чередуй `stats`/`quote`, добавь `montage` на кульминацию |
| Текст в 9:16 обрезан | заголовок ≤ 6 слов, `sub` ≤ 12 |
| Скриншот мыльный | положи PNG в `assets/` в исходном разрешении, не растягивай |
| Клип в начале | добавь `title` с `vo` или увеличь `duration` первой сцены |

## Публикация

- Заголовок: 40–60 символов, без ALL CAPS.
- Описание: первые 2 строки — крючок, потом таймкоды и ссылки.
- Обложка: кадр из ролика с крупным текстом; `remotion still` на нужном кадре.
- Субтитры: загрузить `subtitles.srt` отдельно (плюс они вшиты в кадр).
