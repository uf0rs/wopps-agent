# Режиссура: из брифа в раскадровку

## 1. Разбери бриф

Выпиши до начала сцен:

| Что | Зачем |
|---|---|
| Зритель | от этого зависит лексика и длина фраз |
| Одно обещание | что человек должен запомнить через неделю |
| Одно действие | что он делает после ролика (ссылка, подписка, звонок) |
| Доказательство | цифра, демо, код, скриншот, цитата |
| Длительность | 15 / 30 / 60 / 90 / 180 с |

Нет доказательства — не выдумывай: строй ролик на демонстрации процесса.

## 2. Каркас по длительности

**15 с (5–6 сцен):** хук → доказательство → CTA.
**30 с (7–9 сцен):** хук → проблема → доказательство → результат → CTA.
**60 с (8–11 сцен):** хук → контекст → проблема → как работает (2–3 сцены) → доказательство → поворот → CTA.
**90 с (12–15):** добавь сцену «что ломалось» и одну тихую сцену перед финалом.
**3 мин (16–20):** классическая драматургия: завязка, обострение, механизм, доказательство, честные ограничения, финал.

Правило: **не больше одной новой мысли на сцену**. Если в голове две — это две сцены.

## 3. Ритм

- Смена фона/типа сцены каждые 3–6 сцен, иначе глаз устаёт.
- После плотной сцены (`stats`, `montage`, `code`) — воздух: `quote` или `statement`.
- Первые 3 секунды — самый крупный текст и самый сильный звук.
- Финал не длиннее 6 секунд: логотип, одна строка, CTA.
- Пауза после ключевой цифры — это тоже монтаж. Дай `stats`/`statement` доиграть.

## 4. Текст

**Заголовки** (на экране): 2–8 слов, без точки, без «мы», без «является».
**Озвучка**: 8–20 слов на сцену, разговорно, в настоящем времени.
**Подписи**: поясняют, а не повторяют заголовок.

Примеры:

| Плохо | Хорошо |
|---|---|
| «Наша компания предлагает инновационное решение» | «Ролик собирается за один прогон» |
| «Оптимизация процессов обработки данных» | «10 минут видео. Один час работы» |
| «Присоединяйтесь к нашему сообществу» | «Ссылка в описании» |

Числа пиши цифрами, если они читаются («16 сцен», «617 секунд»), и словами, если это часть фразы («в два раза быстрее»).

## 5. Форматы

- **16:9** — основной. Слева текст, справа визуал; HUD уместен.
- **9:16** — вертикаль: один смысл на кадр, текст крупнее, подписи внизу, ≤ 6 слов в заголовке.
- **1:1** — соцсети: центр композиции, без мелких деталей по краям.
- **4:5** — лента: как 1:1, но больше воздуха сверху/снизу.

В вертикали `compare` и `steps` автоматически складываются в колонку; не пытайся уместить две колонки.

## 6. Проверка перед сборкой

- [ ] У каждой сцены есть причина существовать.
- [ ] В озвучке нет фраз, которые нельзя произнести без запинки.
- [ ] Заголовки не дублируют озвучку слово в слово.
- [ ] Есть доказательство, а не только заявления.
- [ ] Финал говорит, что делать дальше.
