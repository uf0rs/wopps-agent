---
title: "Commands"
description: "Reference for the uf0rs command line."
---

Every command accepts `--help` for its full flag list, for example `uf0rs run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ uf0rs run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: WOPPS review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @uf0rs/cli
      - run: uf0rs run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ uf0rs run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ uf0rs run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ uf0rs run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ uf0rs run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ uf0rs run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ uf0rs run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ uf0rs run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ uf0rs run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ uf0rs mini
```

Continue the last session.

```bash
$ uf0rs mini --continue
```

Start with a model and an initial prompt.

```bash
$ uf0rs mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ uf0rs mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ uf0rs mini --help
```

## session

Manages sessions.

```bash
$ uf0rs session list
```

Limit the list and print JSON.

```bash
$ uf0rs session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ uf0rs session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ uf0rs session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ uf0rs session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ uf0rs session import session.json
```

Import into a specific directory.

```bash
$ uf0rs session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ uf0rs session --help
```

## auth

Manages AI providers and credentials.

```bash
$ uf0rs auth list
```

List them as JSON.

```bash
$ uf0rs auth list --format json
```

Log in to a provider.

```bash
$ uf0rs auth login anthropic
```

Log in with a specific authentication method.

```bash
$ uf0rs auth login anthropic --method key
```

Log out of a saved account.

```bash
$ uf0rs auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ uf0rs auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ uf0rs auth export anthropic > credentials.json
$ uf0rs auth import credentials.json
```

View all subcommands and flags.

```bash
$ uf0rs auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ uf0rs mcp list
```

Add a remote server.

```bash
$ uf0rs mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ uf0rs mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ uf0rs mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ uf0rs mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ uf0rs mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ uf0rs mcp logout sentry
```

View all subcommands and flags.

```bash
$ uf0rs mcp --help
```

## plugin

Manages plugins.

```bash
$ uf0rs plugin list
```

Include built-in server plugins.

```bash
$ uf0rs plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ uf0rs plugin add @example/uf0rs-tui
```

Check package plugins for updates.

```bash
$ uf0rs plugin check
```

Update package plugins.

```bash
$ uf0rs plugin update
```

Remove a plugin from global configuration.

```bash
$ uf0rs plugin remove @example/uf0rs-tui
```

View all subcommands and flags.

```bash
$ uf0rs plugin --help
```

## stats

Shows shareable usage statistics.

```bash
$ uf0rs stats
```

Show the last 7 days.

```bash
$ uf0rs stats --days 7
```

Show model usage.

```bash
$ uf0rs stats --models
```

Show cost and token details.

```bash
$ uf0rs stats --cost
```

Print JSON instead of a report.

```bash
$ uf0rs stats --json
```

Show only the current project.

```bash
$ uf0rs stats --project .
```

View all subcommands and flags.

```bash
$ uf0rs stats --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ uf0rs serve
```

Bind to all interfaces on a fixed port.

```bash
$ uf0rs serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ uf0rs serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ uf0rs serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ uf0rs pair
```

Use an external URL in the links.

```bash
$ uf0rs pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ uf0rs pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ uf0rs pair --remote --yes
```

View all subcommands and flags.

```bash
$ uf0rs pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ uf0rs service start
```

Restart it.

```bash
$ uf0rs service restart
```

Show its status.

```bash
$ uf0rs service status
```

Stop it.

```bash
$ uf0rs service stop
```

Read a setting.

```bash
$ uf0rs service get hostname
```

Set a setting.

```bash
$ uf0rs service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ uf0rs service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ uf0rs service set env UF0RS_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ uf0rs service unset hostname
```

View all subcommands and flags.

```bash
$ uf0rs service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ uf0rs reload
```

## api

Makes a request to the running server.

```bash
$ uf0rs api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ uf0rs api session.list --param limit=10
```

Send a JSON body.

```bash
$ uf0rs api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ uf0rs api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ uf0rs api --help
```

```bash
$ uf0rs acp
```

View all subcommands and flags.

```bash
$ uf0rs acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ uf0rs debug agents
```

List configuration sources.

```bash
$ uf0rs debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ uf0rs debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ uf0rs debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ uf0rs debug paths
```

Print a single path.

```bash
$ uf0rs debug paths db
```

View all subcommands and flags.

```bash
$ uf0rs debug --help
```

## upgrade

Upgrades WOPPS to the latest or a specific version. Alias: `update`.

```bash
$ uf0rs upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ uf0rs upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ uf0rs upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls WOPPS. Session data, configuration, and
state are not removed.

```bash
$ uf0rs uninstall
```

Preview what would be removed.

```bash
$ uf0rs uninstall --dry-run
```

View all subcommands and flags.

```bash
$ uf0rs uninstall --help
```
